# RSEQ Hockey Scraper

**FR** — Lit l'horaire, le dernier match, l'alignement, les statistiques et le classement d'une équipe de
hockey scolaire du RSEQ (scolaire.rseqhockey.com) et les publie dans Home Assistant sous forme de capteurs
MQTT. Nécessite un service FlareSolverr pour franchir la protection Cloudflare du site. Configuration et
capteurs : onglet **Documentation**, ou <https://github.com/Frazou1/reseqhockey-ha-addon>.

**EN** — Reads the schedule, last game, roster, statistics and standings of a RSEQ school hockey team
(scolaire.rseqhockey.com) and publishes them to Home Assistant as MQTT sensors. Requires a FlareSolverr
service to get past the site's Cloudflare protection. Configuration and sensors: **Documentation** tab, or
<https://github.com/Frazou1/reseqhockey-ha-addon>.
